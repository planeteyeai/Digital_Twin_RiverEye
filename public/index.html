✨ Features

  • Live river monitoring for Mula-Mutha, Mithi, and Mandovi rivers
  • Real-time discharge and water level predictions
  • Flood risk assessment with margin boards
  • Historical data since Jan 2021
  • 72-hour weather forecasts
  • Upload custom river KML files
  • REST API for all data

Quick Deploy

Deploy in 2 minutes with Railway:

npm i -g @railway/cli && railway login && railway init && railway up

NadiTwin uses live data from Open-Meteo, GloFAS, and Copernicus DEM.

No API keys required. Python 3.8+ standard library.
